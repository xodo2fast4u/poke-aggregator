<h2>Overview</h2>
<p>PokéAggregator is a high performance archive and directory designed to aggregate data from major Pokémon fan game communities, including PokeHarbor and Eevee Expo. This project provides a unified, searchable, and paginated dashboard for RPGXP fan games and GBA ROM hacks, focusing on accurate tracking of release dates and latest updates.</p>

<h2>Project Philosophy and Legal Notice</h2>
<p>This project is built on the following core principles:</p>
<ol>
  <li><strong>Creative Expression:</strong> The games listed in this archive are created by fans for purely creative, imaginative, and curious purposes. These developers do not seek profit; they build these experiences to fill a creative void that official channels currently do not address.</li>
  <li><strong>Technological Reality:</strong> Fan creation is a natural byproduct of programming and its universal languages. As long as these coding tools exist, humans will use them to express their imagination. Challenging these creations is essentially a challenge against the existence of programming languages themselves.</li>
</ol>

<h2>Features</h2>
<ul>
  <li>Multi source scraping: Integrates data from various community forums.</li>
  <li>Client side pagination: Smooth performance when browsing hundreds of records.</li>
  <li>Filtering: Search by title, platform (GBA/RPGXP), and development status.</li>
  <li>Sorting: Toggle between <q>Latest Released</q> and <q>Recently Updated</q> views.</li>
  <li>Responsive Design: Optimized for both desktop and mobile viewing.</li>
</ul>

<h2>Installation and Usage</h2>
<ol>
  <li>Clone the repository to your local machine.</li>
  <li>Run <kbd>npm install</kbd> to install dependencies.</li>
  <li>Run <kbd>node scraper.js</kbd> to execute the latest data fetch.</li>
  <li>Run <kbd>npm start</kbd> to launch the local development server.</li>
  <li>Run <kbd>npm run build</kbd> to generate the production build.</li>
</ol>
